# 라이선스

공통 코드와 SDK는 MIT, 공통 글꼴은 해당 OFL과 출처 manifest를 보존한다. 저장소에 들어 있는 예제 SVG 그림은 CC0-1.0으로 제공한다. 공통 묶음의 출처와 해시는 common-bundle.lock.json에 있다.

공통 캠프 배경과 메뉴 SVG는 `game-foundation`의 CC0-1.0 예제 그림이다. AdMob 플러그인은 MIT다. 배포 원본의 라이선스를 `godot/data/licenses`에 보존하고 내보내기에 포함한다. 출처와 고정 해시는 `native/dependencies.lock.json`과 `native/SOURCE.md`에 기록한다.
