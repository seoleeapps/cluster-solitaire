# 출시 체크리스트

이 목록은 실행 결과를 대신하지 않는다. 항목마다 실제로 실행한 근거를 남긴다.

## 빌드 전

- [ ] `npm test`와 CI의 여정, 저장 복원, 390x844와 360x640 렌더 확인
- [ ] `npm run check:release`로 Android 빌드 입력 확인
- [ ] 설계의 인수조건(AC-001~018, AC-101~106) 가운데 개발 환경 항목의 근거
- [ ] 새 화면의 독립 검수 3회 기록

## 빌드와 internal 트랙

- [ ] 버전 원장과 태그 확인
- [ ] 서명 AAB의 패키지, 버전 이름, versionCode, target SDK, 서명 인증서, 파일 해시 확인
- [ ] internal 트랙의 실제 versionCode와 테스터 참여 경로 확인

## 기기와 마켓

- [ ] 승인된 기기 항목 AND-01~08 확인 기록
- [ ] 등록 문구와 이미지, 콘텐츠 등급, 데이터 보안 양식, 광고 포함 신고
- [ ] 심사 제출, 승인, 공개를 각각 기록
- [ ] 공개 뒤 production 트랙의 버전과 스토어 페이지 상태를 다시 읽어 확인

기기에서 광고 SDK의 실제 동작을 확인하지 못한 상태로는 공개 출시로 넘어가지 않는다(설계의 인수조건 절).
