# 시각 방향 기준: B 캔디 팝 (v1)

- 선택: 사용자가 2026-11-21 질문 응답으로 시안 B 캔디 팝을 골랐다(결정 로그 DEC-013). 같은 플레이 상황을 그린 세 방향(A 카드 테이블, B 캔디 팝, C 미드나잇) 가운데 하나다.
- 기준 그림: 이 폴더의 PNG 4장. 390×844 논리 화면을 2배로 그렸다.

| 파일 | 내용 |
|---|---|
| `b-play-ko.png`, `b-play-en.png` | 플레이 화면. 스테이지 12, 날씨 묶음 완성, 과일 4장 선택, 임시 칸에 기타, 3번째 칸 잠김 |
| `b-title-ko.png`, `b-title-en.png` | 타이틀 화면. 준비 완료 상태 |
| `mock-source.html` | 시안을 그린 원본. `?dir=b&lang=ko|en&screen=play|title`. 글꼴과 아이콘 경로는 제작 당시 작업 폴더 기준이라 그대로는 열리지 않는다. 치수와 색 값을 읽는 용도다 |

## 방향 규칙

| 요소 | 규칙 |
|---|---|
| 배경 | 하늘색 `#58C4FF`에서 파랑 `#6E8CFF`, 보라 `#A56BFF`로 내려가는 세로 그라데이션. 흰색 반투명 원이 떠 있다 |
| 카드 | 흰색, 모서리 16, 아래로 6 두께의 연보라 옆면. 아이콘 54, 이름은 둥근 서체 |
| 선택 | 노란 테두리 4와 주황 옆면, 위로 7 들림, 초록 체크 배지. 색만으로 구분하지 않는다 |
| 카드 뒷면 | 보라 그라데이션에 흰 물방울 무늬, 흰 안쪽 테두리 |
| 완성 묶음 | 위쪽 한 줄의 원형 메달 4개. 완성하면 흰 원 안에 아이콘 4개와 산호색 이름표 |
| 받침 | 흰색 20% 반투명 둥근 판 안에 임시 칸 줄(3칸, 가운데 정렬)과 예비 카드 줄(4칸) |
| 주 버튼 | 노랑에서 주황으로 가는 그라데이션, 흰 글자, 아래 7 두께의 짙은 주황 옆면, 흰 외곽선 |
| 부스터 | 원형 버튼(힌트 하늘색, 되돌리기 보라), 흰 외곽선, 오른쪽 위 빨간 숫자 배지, 아래 이름 |
| 상단 | 흰 사각 일시정지, 노란 스테이지 표지, 하트 4개, 짙은 반투명 코인 칩과 초록 더하기 |
| 서체 | 제목과 버튼은 Fredoka(영문)와 Jua(한글), 본문은 Noto Sans KR |

실제 실행 화면과의 비교 기록은 `docs/game-design/ui/` 아래에 남긴다.
