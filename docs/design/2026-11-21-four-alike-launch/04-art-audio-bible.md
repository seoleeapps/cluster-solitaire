# 아트 오디오 바이블

- 문서 상태: approved
- 승인 근거: 사용자 질문 응답 2026-11-21 (DEC-013 시각 방향 B 캔디 팝, DEC-003 Fluent Emoji Flat 아이콘, DEC-016 배경음악 생성 API)
- Source of truth: 아트 방향, 에셋 목록과 출처, 연출 언어, 소리와 진동, 라이선스

## 아트 방향

방향 이름은 캔디 팝이다. 밝은 하늘에서 보라로 번지는 배경 위에 두툼한 흰 카드가 놓이고, 누르면 통통 튀는 캐주얼 퍼즐의 인상을 준다. 기준 그림은 `docs/game-design/ui/direction/`의 네 장이며 사용자가 2026-11-21에 세 방향 가운데 골랐다.

| 축 | 규칙 |
|---|---|
| 분위기 | 밝고 가볍고 친절하다. 어둡거나 사실적인 재질은 쓰지 않는다 |
| 형태 | 둥근 모서리, 원과 알약 모양. 뾰족한 모서리와 얇은 선 장식은 쓰지 않는다 |
| 두께 | 그림자 대신 아래쪽 옆면으로 두께를 보인다. 흐린 그림자는 떠 있는 것(선택한 카드, 팝업)에만 쓴다 |
| 색 | 배경은 파랑과 보라, 카드는 흰색, 행동은 주황과 노랑, 확인은 초록, 완성은 산호. 한 화면에서 주황 주 버튼은 하나만 둔다 |
| 대상 연령 | 성인 캐주얼. 스토어 그림과 아이콘은 유아용으로 보이지 않게 카드와 글자 중심으로 구성한다(리서치 POL-13) |

## 시각 문법

| 요소 | 문법 |
|---|---|
| 카드 | 흰 판, 모서리 16, 아래 옆면 6(연보라), 가운데 위에 아이콘, 아래에 이름. 뒷면은 보라 그라데이션에 흰 물방울 무늬와 흰 안쪽 테 |
| 선택 | 노란 테 4와 주황 옆면, 초록 체크 배지 |
| 칸 | 짙은 남색 22% 판, 안쪽 위에 얕은 음영. 잠긴 칸은 금색 테 3과 자물쇠 |
| 받침 | 흰색 20% 판과 흰색 40% 테, 모서리 22 |
| 버튼 | 주 버튼은 주황 그라데이션과 흰 외곽선 3, 옆면 7, 위쪽 광택. 보조 버튼은 흰 판과 연보라 옆면. 원형 버튼은 흰 외곽선과 색 그라데이션 |
| 배지 | 빨간 원과 흰 테, 숫자는 제목 서체 |
| 글자 | 배경 위 글자는 흰색에 남보라 그림자(아래 2). 카드 위 글자는 남보라 `#3A3470` |
| 아이콘 | 카드 그림은 Fluent Emoji Flat, 화면 조작 아이콘은 굵기 3의 둥근 선 그림(흰색 또는 남보라) |

## 캐릭터와 세계

캐릭터와 이야기는 없다. 세계는 "카드가 놓인 밝은 놀이판" 하나다. 카드 그림 845종이 내용물이고, 범주 이름이 드러나는 순간이 연출의 중심이다. 꾸미기 요소는 카드 뒷면 4종(보라 물방울, 민트 줄무늬, 산호 하트, 남색 별)과 배경 4종(기본 하늘 보라, 노을 복숭아, 민트 청록, 밤 남색)이다.

## UI 아트 경계

| 엔진이 맡는 것 | 그림이 맡는 것 |
|---|---|
| 배치, 글자, 숫자, 입력, 상태 전환, 색 그라데이션 배경, 입자 | 9분할 스킨 8장, 카드와 칸과 메달과 버튼의 판, 조작 아이콘, 카드 그림 |

- 공통 화면(타이틀의 버튼과 진행 막대, 팝업, 설정)은 `godot/game/skins/candy_pop/`의 스킨과 그것으로 만든 `theme.tres`를 쓴다. 코드로 단색 사각형 판을 조립하지 않는다.
- 늘어나는 그림은 9분할 여백을 `skin.json`과 장면의 패치 여백에 적는다. 카드 판은 좌우 20, 위 20, 아래 29다.
- 카드 그림은 192px PNG로 싣고 화면에서는 38~54로 줄여 쓴다.

## VFX 언어

| 순간 | 연출 | 길이 |
|---|---|---|
| 카드 배치 | 위에서 한 장씩 내려와 자리에 앉고 맨 앞 카드가 뒤집힘 | 장당 30ms 간격, 전체 0.6초 |
| 묶음 완성 | 카드가 메달로 모이고 메달에서 색 입자 12개가 퍼짐 | 0.5초 |
| 오답 | 카드 흔들림, 하트가 두 조각으로 갈라지며 회색으로 | 0.3초 |
| 클리어 | 화면 위에서 색종이 입자 40개, 제목 글자가 튀어나옴 | 1.2초 |
| 별 | 별이 커졌다 줄며 자리 잡고 반짝임 입자 6개 | 별마다 0.25초 |
| 코인 | 코인 6개가 칩으로 날아가고 숫자가 올라감 | 0.6초 |
| 강조 | 받을 것이 있는 버튼과 막힌 길의 부스터는 2초 주기로 4% 커졌다 돌아옴 | 반복 |
| 배경 | 흰 원 4개가 20~30초 주기로 천천히 떠다님 | 반복 |

입자는 공통 기반의 `burst`와 `sparkle`을 색만 바꿔 쓴다. 움직임 줄이기 설정에서는 입자와 떠다님을 끄고 페이드만 남긴다.

## 오디오와 햅틱

| 사건 | 소리 | 진동 |
|---|---|---|
| 카드 선택, 해제 | `card_select`(고른 수에 따라 음높이 4단계), `card_deselect` | 약 10ms |
| 임시 칸 이동, 카드 뒤집힘 | `card_slide`, `card_flip` | 약 10ms |
| 묶음 완성 | `group_complete` | 25ms |
| 오답, 한 장 차이 | `miss`, `one_away` | 15ms 두 번 |
| 막힘, 막힌 길 | `stuck` | 없음 |
| 힌트, 되돌리기, 칸 열기 | `hint`, `undo`, `slot_unlock` | 약 10ms |
| 부스터 받음 | `booster` | 없음 |
| 클리어, 실패 | `win`, `fail` | 40ms, 없음 |
| 별, 코인 | `star_1`~`star_3`, `coin` | 약 10ms |
| 버튼, 팝업, 보상 | 공통 `tap`, `confirm`, `cancel`, `error`, `reward_sting` | 없음 |
| 배경 | `bgm_main` 반복. 광고가 뜨는 동안과 앱이 뒤로 갔을 때 멈춤 | 없음 |

버스는 Music과 SFX 둘이고 설정에서 따로 끈다. 음악 기본 음량은 효과음보다 8dB 낮게 둔다. 배경음악과 효과음의 청취 확인은 사용자가 듣고 판단하며, 수치 확인(반복 이음 지표 0.0006, 기준 0.0025)과 구분해 기록한다.

## 생성과 라이선스

| 대상 | 도구와 설정 | 라이선스와 고지 |
|---|---|---|
| 카드 그림 | `microsoft/fluentui-emoji` 커밋 `1ffb34c`의 Flat SVG를 192px PNG로 변환 | MIT. 저작권 표시와 허가문을 `godot/data/licenses/FluentEmoji-MIT.txt`에 싣고 설정의 오픈소스 고지에서 보여 준다 |
| 스킨과 플레이 그림 | 저장소의 생성 스크립트(색과 치수 상수). 다시 만들면 바이트까지 같다 | 자체 제작 |
| 효과음 | 저장소의 합성 스크립트(표준 라이브러리만 사용) | 자체 제작 |
| 배경음악 | Stable Audio 2.5, 90초 생성 뒤 3초 겹쳐 이음. 프롬프트: bright cozy casual puzzle game background music, playful marimba melody, soft plucked ukulele, warm electric piano chords, light hand percussion and shaker, cheerful but calm, medium tempo, gentle. 2026-11-21 생성, API 호출 1회 | Stability AI 이용 약관에 따른 생성물. 원본 WAV는 저장소 밖에 보관한다 |
| 서체 | 공통 묶음 | OFL 본문을 `LICENSES/`와 설정에 싣는다 |

브랜드를 떠올리게 하는 그림(특정 상표 모양)은 카드에서 뺀다. 주류 소재 카드는 등급을 위해 뺐다.
